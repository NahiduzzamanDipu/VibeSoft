# Instructions for Gemini CLI

Before installing skills, read `README.md`, `INSTALL.md`, `SKILL-CATALOG.md`, and `SECURITY.md`. Use only skills marked `approved` and `installable` in `manifest/skills.json`. Confirm the agent and destination scope with the user by showing a dry-run plan first. Do not run third-party scripts, install standalone security tools, replace existing files without explicit approval, or scan systems without exact written authorization and scope. Verify each copied `SKILL.md` before reporting success.
