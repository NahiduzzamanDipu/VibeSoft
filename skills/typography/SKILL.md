# Typography

Choose type for the product, audience, language, content, and platform. Inspect existing font assets, licenses, loading behavior, and tokens first. Do not choose a font pair for novelty alone.

- Assign clear roles to display, heading, body, label, and data text.
- Set a useful scale, line-height, weight, and measure using real text and realistic content length.
- Check language glyph coverage, fallback behavior, numeral alignment, and wrapping where relevant.
- Preserve readability at small sizes and narrow viewports; avoid using weight or color alone to express hierarchy.
- Load local or approved fonts efficiently. Do not add remote font requests without a project reason.
- Verify headings, paragraphs, controls, tables, and dense data at zoom and responsive widths.

Report the type choices and any tested sizes. If no browser preview was available, mark visual typography as unverified.
