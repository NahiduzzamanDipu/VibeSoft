# Accessibility Review

Use the applicable WCAG target and the project's accessibility tools where available. Inspect actual flows; automated results are evidence, not proof of conformance.

- Check semantic structure, landmarks, headings, names/labels, useful image text alternatives, and status/error announcements.
- Operate all primary controls with keyboard; inspect focus order, visibility, dialogs, menus, and focus restoration.
- Check text and non-text contrast, zoom/reflow, text resizing, and content not conveyed only by color, position, or motion.
- Check form instructions, validation, error association, and recovery.
- Respect reduced-motion preferences and ensure functionality without animation.
- Check target size and touch use for the relevant platform.

Record the route/component, method, evidence, severity, and exact remediation. Separate checks actually performed from those not run; do not state a conformance level without sufficient review.
